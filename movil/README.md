# Aplicación móvil

Flutter a cargo de Jaziel. La base se desarrolla en #17 y el flujo de focos de calor en #20. Esta carpeta aún no contiene una aplicación Flutter generada.

La URL del backend debe poder configurarse para emulador o dispositivo. El cliente móvil no contiene las claves privadas de los proveedores. Se comparte el contrato de la API y se conservan procedencia, unidades, fechas y estados de los resultados.
