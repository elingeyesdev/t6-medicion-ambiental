# Recursos compartidos

- [Contrato implementado de la API candidata y pruebas para clientes](api/README.md).

Los contratos, las definiciones de consulta y el catálogo territorial se coordinan entre Laravel/Blade y Flutter. El catálogo y sus límites se preparan en #16 con fuente, versión, jerarquía y validaciones verificables.

Los documentos acordados de DOC-12 y las restricciones de DOC-14 son los antecedentes de diseño. No se presentan como endpoints o métodos ya implementados.

La propuesta de catálogo está en [territorios/README.md](territorios/README.md). Contiene fuente y licencia, 72 registros con sus geometrías, correspondencia con nombres INE 2024, reglas ejecutables y una herramienta local de revisión. Su adopción por ambos integrantes permanece pendiente del PR de #16.
