# Logo elegido de GeoSur

Josué eligió la tercera propuesta, **Trama ambiental**, el 28/10/2026. Referencia: PR #70 y tarea #69.

El símbolo GS se adaptó a SVG para conservar la nitidez en cabecera, acceso, menú y favicon. Verde para vegetación, azul para agua y terracota para suelo/calor. La imagen original y los prompts permanecen en la rama de propuestas del PR #70.

El componente compartido usa `web/public/img/marca/geosur-simbolo.svg`. La palabra GeoSur se mantiene como texto accesible, con la tipografía del panel; no se incrusta texto diminuto dentro del símbolo. La elección no cambia el nombre, los datos ni el alcance del sistema.

Se comprobó en escritorio, menú móvil a 390 px y tema oscuro. Capturas en `docs/evidencias/sensores66/`; el mismo componente se utiliza en las otras pantallas y el favicon apunta al SVG elegido. La decisión de diseño no autoriza una promoción de M3 a main.
