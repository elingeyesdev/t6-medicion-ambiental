# Historial del mapa #62

Prueba con la cuenta local Visualizador y las lecturas simuladas de Demostración ya existentes. No se cambió el rol ni se publicaron lecturas nuevas.

1. Elegir Santa Cruz, Temperatura y Solo simulados.
2. Abrir Santa Cruz y fijar una lectura como referencia.
3. Activar Ver por momento y cambiar fecha/hora; comprobar la lectura y la diferencia, conservando la referencia.
4. Avanzar una hora y comprobar otra lectura. Ver ambas ubicaciones y quitar la comparación.
5. Comprobar que una fecha sin lecturas conserva el punto sin inventar valores.

`comparacion-momentos.png` muestra la referencia y la selección con sus fechas, valores y origen. `comparacion-ciudades.png` muestra Santa Cruz y Buenos Aires, con A/B en las coordenadas de sus lecturas. `resultado-pruebas.txt` registra 371 pruebas de Laravel y 3457 comprobaciones.
